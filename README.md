# 🌟 Lumi

> Uma plataforma educacional desenvolvida para tornar o aprendizado infantil mais interativo, divertido e acessível, oferecendo também ferramentas que auxiliam professores no acompanhamento do desenvolvimento de seus alunos.

## 📖 Sobre o Projeto

O **Lumi** é um projeto desenvolvido como **Trabalho de Conclusão de Curso (TCC)**, com o objetivo de aproximar a tecnologia do ambiente educacional.

A plataforma reúne **atividades lúdicas, educativas e interativas** para crianças, proporcionando uma experiência de aprendizado mais dinâmica e envolvente.

Além disso, o Lumi disponibiliza uma **sala de aula virtual para professores**, permitindo:

* 📚 Criar e organizar atividades;
* 👨‍🏫 Gerenciar turmas;
* 📊 Acompanhar o desempenho dos alunos em tempo real;
* 📈 Facilitar o planejamento das aulas por meio de uma plataforma simples e intuitiva.

Nosso propósito é contribuir para uma educação mais moderna, utilizando a tecnologia como ferramenta de apoio ao ensino.

# 🤝 Como contribuir

## 🛠️ Pré-requisitos

Antes de iniciar, certifique-se de possuir:

* Uma conta no GitHub;
* Acesso ao repositório como colaborador;
* GitHub Desktop instalado;
* Git instalado;
* Visual Studio Code (ou outra IDE de sua preferência).

## 📥 Clonando o projeto

> Este procedimento é realizado apenas uma vez.

1. Abra o **GitHub Desktop**.
2. Selecione:

```text
File
→ Clone Repository
```

3. Na aba **GitHub.com**, escolha o repositório **TCC**.
4. Selecione uma pasta no computador.
5. Clique em **Clone**.

Pronto! Agora você possui uma cópia local do projeto.

## 🔄 Atualizando o projeto

Antes de iniciar qualquer tarefa:

1. Clique em **Fetch Origin**.
2. Caso existam alterações, clique em **Pull Origin**.

Dessa forma, você sempre trabalhará com a versão mais recente do projeto.

## 🌿 Criando uma nova Branch

Nunca desenvolva diretamente na branch **main**.

No GitHub Desktop:

```text
Current Branch
→ New Branch
```

Escolha um nome que identifique a funcionalidade que será desenvolvida.

## 💻 Desenvolvendo

Realize normalmente as alterações no projeto utilizando sua IDE.

Ao finalizar uma parte importante da funcionalidade, salve todos os arquivos.

## ✅ Criando um Commit

Abra novamente o **GitHub Desktop**.

Na aba **Changes**, confira os arquivos modificados.

No campo **Summary**, escreva uma breve descrição da alteração realizada.

Depois clique em:

```text
Commit to <nome-da-branch>
```

## ☁️ Enviando a Branch

Após realizar o commit, clique em:

```text
Push Origin
```

Sua branch será enviada para o GitHub.

## 🔀 Abrindo um Pull Request

Após o Push, clique em:

```text
Create Pull Request
```

O navegador será aberto automaticamente.

Informe um título e uma breve descrição da alteração e, em seguida, clique em **Create Pull Request**.

## ✔️ Finalizando

Após a aprovação do Pull Request, ele poderá ser integrado à branch **main**.

Antes de iniciar uma nova funcionalidade:

* volte para a branch **main**;
* clique em **Fetch Origin**;
* depois em **Pull Origin**.

Assim sua cópia local permanecerá sincronizada com o repositório.

## 📋 Boas práticas

* Atualize o projeto antes de começar uma nova tarefa.
* Trabalhe sempre em uma branch própria.
* Faça commits sempre que concluir uma etapa importante.
* Envie suas alterações utilizando **Push Origin**.
* Abra um Pull Request para integrar sua funcionalidade.
* Após o Merge, atualize sua branch **main** antes de iniciar uma nova tarefa.
